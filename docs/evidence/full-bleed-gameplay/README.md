# Full-bleed gameplay evidence

These screenshots were captured in a browser from `PlayMode`, `StageHole`, the production normal-hole and physical-putting renderers, and the existing HUD and dock at `http://localhost:3000/dev/full-bleed-evidence`. The route uses checked-in, backend-generated Generator 8 geometry and physical-green states; the event title and shot-control guidance are representative fixture data. No static artwork was substituted for a renderer. `layout=before` renders the same fixture in the prior stacked composition. The route returns 404 in production.

The desktop viewport is **1600 × 900**; the narrow viewport is **390 × 844**. Each before/after pair uses the same fixture and dimensions.
