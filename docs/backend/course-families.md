# Course-family inventory

New worlds use four procedural presentation families: Parkland (`PARKLAND`), Links (`LINKS`), Heathland (`WOODLAND`), and Desert (`DESERT`). The persisted course classification enum still has six members. `MOUNTAIN` and `COASTAL` are retained for historical worlds. `TROPICAL` and `HEATHLAND` are presentation tokens, not persisted course classifications.

The world generates one seed-derived course pool shared by both tours. It cycles through the selected classifications by pool index. Development events display their host course's classification: `WOODLAND` is presented as Heathland, and legacy `COASTAL` as Coastal/Tropical. Generator 8 uses one course-generation pipeline with classification-specific exposure, water/tree biases, enclosure, hazard, and geometry choices. `PARKLAND` and `WOODLAND` have different generation calibration, but not independent generator implementations. Premium Parkland V2 remains eligible only for live Generator 8 canonical `PARKLAND` holes with a Parkland event scene. The non-Parkland renderers remain available.

Pro events have fixed names, locations, and *scene tokens*, but their host course indices are assigned from the same generated pool. The curated Pro scenes are Parkland (nine of 15 regular/signature stops, three majors, and the Tour Championship), Links (two stops and the Seaside Open major), Desert (Desert Mountain Challenge), Coastal (Coastal Heritage Classic), Tropical (Sunshine State Showdown), and Mountain (Blue Ridge Mountain Open). Those three scene exceptions have no established equivalent replacement in the current calendar and remain as authored. Their generated host courses in a new world still belong to the core pool. This existing distinction means a Pro event's scene need not match its host classification.

Course-pool selection is pinned in the world snapshot separately from the generator version. New worlds use `CORE_FOUR`; saves without this field restore `LEGACY_SIX` so existing tournament indices, course identities, geometry, and results retain their meaning. Both policies retain Generator 8 and earlier generator support.

The requested dense Woodland and open Parkland visual variations do not yet share a Parkland presentation foundation: `WOODLAND` currently routes to Heathland. Changing that routing for old saves would alter their presentation, so this consolidation keeps the historical mapping. A later scoped visual-calibration change can add Parkland-family density variants while preserving the saved classification and scene provenance.
