# Design

- `StageHole` passes its existing premium/polished presentation to `PhysicalPuttingGreen`.
- `premiumPuttingFamily` checks course provenance and canonical green/fringe geometry. Failure keeps the existing renderer.
- `PremiumPuttingTerrain` uses the actual region boundaries, approved SVG material stops and construction techniques, and seeded decorative clearance. It never contributes to hit testing or game state.
- The physical projector remains uniform. Premium framing supplies more visual context for longer putts and uses its inverse for pointer input at desktop and narrow widths.
- Natural contours and Read Green arrows come exclusively from `physicalGreen` DTOs; the existing control still determines visibility.
- Existing pace, result mutation, trajectory animation, and shot sequence remain unchanged.
