# Persistent Development Tour catalogue

Give newly created standard worlds the approved 20 permanent Development Tour events and distinct procedural hosts. Keep the existing weeks, tiers, competitive calculations, Pro Tour, and majors. Pin catalogue provenance so existing saves retain their venue-derived event names, hosts, history, and future rotation.

The Development venue registry has 54 lightweight recipes: one for each of three fixed events and three for each of 17 rotating events. Full courses are generated lazily with the world's retained generator version. The existing shared course pool and Pro host assignment are unchanged.
